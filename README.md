# 🛸 Rick and Morty: Interdimensional Portal Terminal

Este proyecto es una plataforma interactiva que consume la **API de Rick and Morty**, permitiendo a los usuarios escanear el multiverso en busca de personajes, visualizar detalles específicos y filtrar especímenes por especie.

---

## 🛠️ Tecnologías Utilizadas

* **React.js**: Arquitectura de componentes.
* **React Router**: Gestión de dimensiones (Rutas).
* **SCSS / CSS3**: Estilos de neón y diseño responsivo.
* **Fetch API**: Conexión con el servidor interdimensional.

---

## 🚀 Características Principales

### 1. Base de Datos de Personajes
Visualización de todos los personajes del multiverso en una cuadrícula holográfica.
* **Cards Responsivas**: Se adaptan perfectamente a dispositivos móviles y escritorio.
* **Efectos Neón**: Estética de ciencia ficción con efectos de hover avanzados.

### 2. Filtro Dimensional por Especie
Un panel exclusivo donde puedes filtrar personajes según su naturaleza biológica o robótica.
* **Lógica de Paginación**: Navegación fluida a través de todos los resultados.
* **Portal dinámico**: Interfaz que reacciona según la selección del usuario.

### 3. Expediente Detallado
Al seleccionar un personaje, se abre un expediente completo con información de origen, estado actual y lista de episodios.



## 💻 Instalación para Científicos

Si deseas clonar esta dimensión en tu entorno local, sigue estos pasos:

1.  **Clonar el repositorio**
    ```bash
    git clone [https://github.com/tu-usuario/rick-morty-portal.git](https://github.com/tu-usuario/rick-morty-portal.git)
    ```
2.  **Instalar dependencias**
    ```bash
    npm install
    ```
3.  **Iniciar el motor de curvatura**
    ```bash
    npm run dev
    ```
